# Step & Points Tracker App 🏃‍♂️🪙

تطبيق لتتبع الخطوات اليومية وتحويلها إلى نقاط تنافسية.

## 🎯 قواعد نظام النقاط (Gamification Rules)
- **كل 1,000 خطوة:** 10 نقاط.
- **إكمال الهدف اليومي (8,000 خطوة):** 50 نقطة إضافية.
- **المواظبة اليومية (Streak):** نقاط مضاعفة عند الاستمرار لعدة أيام.

## 🛠️ التقنيات المستخدمة
- **الإطار:** Flutter / Dart
- **قاعدة البيانات:** Firebase / Local Storage
- **إدارة النسخ:** GitHub
